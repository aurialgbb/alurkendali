# Presentations and PDF reports

## Shared translation

Carry over Inter (or a deliberate available substitute), ink text, blue emphasis, pale contextual surfaces, left alignment, readable diagrams and disciplined spacing. Translate the hierarchy rather than screenshotting the website. Replace motion with a clear completed state or numbered sequence. Use actual supplied data; label any permitted illustrative data.

Use the relevant authoring skill/tool when available. Style guidance alone does not create or validate a PPTX/PDF file.

## PPTX

Default to 16:9 only when no format was specified. Use an editable theme/master and native text, shapes, tables and charts wherever practical. Suggested starting sizes: titles 30–38pt, body 18–24pt, captions 12–14pt. Fit the content by editing or splitting slides instead of shrinking everything.

One main point per slide. A useful visual vocabulary is: statement with evidence, process diagram, before/after comparison, finance table with a highlighted takeaway, and restrained summary. Vary composition with purpose while keeping margins and type roles stable. Preserve editable source objects; do not rasterize whole slides to hide rendering issues. Check font substitution, wrapping, overlap and chart labels in rendered slides.

If both PPTX and a slide PDF are requested, export PDF from the same final deck so both agree. Recheck the exported PDF.

## PDF reports

Determine whether the request is a slide export or a paginated report. For a report, A4 is a reasonable default in this user's context; body text around 10.5–12pt and headings around 18–26pt are starting values. Use running headers/page numbers when they aid navigation. Handle table continuation headers, page breaks, footnotes, source labels and totals deliberately.

Keep text selectable and fonts embedded where supported. Use vector charts/diagrams when practical. Review every rendered page for clipped tables, awkward breaks, orphan headings and unreadable captions. Deliver an editable source as well if the user requested later editing.

For the same short visual composition, editable PPTX generally has more layout constraints than a fixed PDF. Long reports with multi-page tables may be more complex than slides. Do not promise that PDF is always easier.

## Useful brief

Infer what is already known. Missing details that most affect quality are audience and purpose, content/data source, slide/page count, aspect ratio/page size, and editability. Ask only for genuinely necessary missing inputs; otherwise state assumptions and proceed. The user can invoke this skill with “Use $controlled-flow-design for a 10-slide editable finance review deck, 16:9, using the attached data; export a matching PDF.”
